1. Introduction

1.1 Project Overview & Purpose

Cartiva is an innovative, full-stack collective e-commerce platform designed to overcome the fundamental inefficiency of traditional retail pricing. In conventional web shopping, individual customers purchase goods in isolation, paying standard retail markup regardless of how many other individuals in the market desire the same product.

Cartiva transforms this dynamic by empowering customers to pool their demand into time-bounded Group Buying Sessions. By aggregating individual orders into collective batches, customers unlock pre-negotiated wholesale price tiers—effectively democratizing factory-rate pricing for retail consumers.

1.2 Problem Statements & Practical Motivation

  • High Retail Penalties for Individuals: Solo shoppers pay excessive retail markups that fail to reflect the economies of scale that sellers could offer on high-volume transactions.
  • Coordination Friction: Informal bulk purchasing organized through chat applications suffers from high cancellation rates, lack of payment security, and complex logistics.
  • Static Pricing Models: Existing platforms in Bangladesh (such as Daraz or Chaldal) use rigid prices that never adjust dynamically to real-time collective demand.
The Cartiva Value Proposition: Buyers save up to 40% on electronics, lifestyle, and grocery products by sharing deals with friends and peers, while merchants move large inventory batches with zero additional customer acquisition cost.

2.2 Core Group Buying & Dynamic Tier Engine

Every product on Cartiva supports configurable volume discounts. When a buyer initiates or joins a group:

  • A unique alpha-numeric code is assigned (e.g., GRP-HOODIE05) alongside a 24-hour expiration window.
  • The interface displays a real-time slot progress bar (e.g., 4 of 5 joined • 1 slot left) and calculates the precise financial savings.
  • If the member quota is reached before the deadline, the session transitions to completed, and the wholesale price is locked.
  • If the campaign expires without meeting the required quota, the session transitions to expired, and payments are automatically marked for refund.

3. Implementation & Technical Architecture

3.1 Technology Stack

  • Backend Engine: Laravel 12 (MVC), PHP 8.3, Eloquent ORM, Session & Cookie Security.
  • Frontend Framework: Laravel Blade Templates, Tailwind CSS (Utility-First Responsive UI), Alpine.js (Reactive Timers & Data-binding).
  • Asset Bundler: Vite 7 with automated manifest caching and minification.
  • Database: Clever Cloud Managed MySQL 8 (20 normalized tables with foreign key cascades).
  • Cloud Serverless Hosting: Vercel Edge Serverless Function runtime with continuous integration (CI/CD) via GitHub main branch.

3.2 Key Code Highlights

Mathematical Discount Calculation (Product.php)

public function getDiscountPercentAttribute(): int
{
    if ($this->single_price > 0 && $this->single_price > $this->group_price) {
        return (int) round((($this->single_price - $this->group_price) / $this->single_price) * 100);
    }
    return 0;
}

4. Discussion, Evaluation & Future Scope

4.1 Comparative Evaluation

Compared to domestic platforms like BDSHOP GroupBuy or ShareDeal, Cartiva introduces automated multi-level tiered discounts rather than a binary flat discount. Compared to Pinduoduo, Cartiva is tailored to the local socio-economic environment with bilingual typography (Inter + Hind Siliguri) and simulated Bangladeshi MFS workflows (bKash/Nagad).

4.2 Engineering Challenges Overcome

  • MySQL 8 Cloud Migration: Resolved legacy MariaDB client authentication incompatibilities by scripting native PHP PDO data transfer scripts to Clever Cloud.
  • Vercel Serverless File System Isolation: Solved read-only filesystem restrictions by redirecting Blade compilations and session handles to Linux /tmp.
  • Mixed Content Asset Blocking: Eliminated HTTP/HTTPS browser security blocking by configuring trusted proxies and forcing SSL URL schemes globally.
  • Connection Pool Optimization: Handled Clever Cloud's 5-connection limit by disabling persistent PDO sockets and triggering explicit disconnection cycles.

4.3 Future Scope

Future development milestones include integrating live commercial MFS payment gateway APIs (SSLCommerz/bKash), deploying WebSockets via Laravel Reverb for instantaneous multi-peer synchronization, and developing native Android/iOS mobile clients using Flutter.

4.4 Conclusion

Cartiva successfully realizes the academic and functional specifications set forth for CSE 3200: Web Engineering Project. Operating live on modern cloud infrastructure, it serves as a robust proof-of-concept for scalable, community-oriented social commerce.
